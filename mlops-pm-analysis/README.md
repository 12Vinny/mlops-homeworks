## Короткий опис задачі
У рамках цього проєкту було проведено PM-аналіз ML-експериментів із класифікації видів ірисів (Iris classification). Мета завдання — не виконувати технічне налаштування, а оцінити результати з позиції AI Project Manager: визначити найкращу модель, перевірити зрілість процесу трекінгу (MLflow) та моніторингу (Prometheus/Grafana), а також ухвалити рішення щодо подальшого розгортання.

## Використані дані та матеріали
Аналіз базується на наданих ментором матеріалах:
* Дані датасету: 150 квіток, 3 класи (збалансовані), split_random_state=7.
* Скриншоти MLflow UI з метриками (Accuracy, Loss) та параметрами п'яти експериментів.
* Скриншоти збережених артефактів.
* Дані експортера Prometheus (графіки та таблиці mlflow_accuracy / mlflow_loss). Усі скриншоти зберігаються в директорії `screenshots/`.

## Обраний кандидат
Для подальшого тестування обрано run **`rf-depth3`** (Random Forest). Він перевершив baseline за показниками Accuracy (0.956) та Loss (0.141), а головне — це єдиний експеримент, для якого було успішно збережено повний пакет артефактів моделі, що уможливлює її відтворення.

## Ухвалене PM-рішення
