# Acceptance Criteria

## Dockerfile та збірка
* Fat image використовує базовий образ python:3.13.
* Slim image використовує базовий образ python:3.13-slim.
* Slim image зібраний із застосуванням підходу multi-stage build.
* У репозиторії присутній та коректно налаштований файл .dockerignore.
* У slim image відсутні зайві файли (кеш пакетного менеджера, build-залежності, непотрібні системні утиліти).
* Обидва образи (fat та slim) збираються з нуля без помилок.

## Запуск та Inference
* Обидва образи успішно запускаються за допомогою стандартної команди docker run.
* Для тестування fat і slim образів використовується повністю однаковий test input (тестове зображення).
* Процес inference коректно відпрацьовує та повертає top-3 prediction для переданого зображення.
* Результат inference (top-3 класи та їхні ймовірності) у fat і slim образах абсолютно збігається.

## Документація та звітність
* README.md містить зрозумілі, готові до копіювання команди для build та run обох образів.
* report.md містить чітке порівняння fat і slim образів (розмір образу, час збірки, час виконання).

## Definition of Done
Задача вважається виконаною, якщо будь-який член команди може клонувати репозиторій, виконати команди з README.md, зібрати fat і slim image, запустити inference на однаковому input і побачити однаковий результат prediction, не вносячи жодних змін у код чи конфігурацію.
